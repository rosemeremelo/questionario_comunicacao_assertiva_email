# 🚀 Avaliação de Assertividade — Autoconhecimento


Este projeto é uma ferramenta interativa de autodesenvolvimento desenvolvida para o programa **AUTOCONHECIMENTO**. 
O aplicativo permite que líderes e aspirantes avaliem seu nível de assertividade através de um questionário de 36 perguntas, 
com envio automático de resultados detalhados por e-mail.



## 📋 Sobre o Projeto

O objetivo desta avaliação é proporcionar uma reflexão honesta sobre comportamentos reais no ambiente de liderança. Ao final, 
o usuário recebe uma pontuação e uma classificação baseada em perfis comportamentais.

### Principais Funcionalidades:
- **Questionário Dinâmico:** 36 questões geradas via JavaScript.
- **Barra de Progresso:** Feedback visual em tempo real do avanço do usuário.
- **Design Responsivo:** Adaptado para dispositivos móveis (Mobile First).
- **Integração com E-mail:** Envio do relatório de desempenho diretamente para o e-mail do usuário via **EmailJS**.
- **Dark Mode:** Interface moderna e sofisticada utilizando cores institucionais.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias fundamentais da web, seguindo boas práticas de organização:

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização avançada com uso de variáveis CSS, Flexbox e animações de transição.
* **JavaScript (ES6+):** Lógica de cálculo, manipulação do DOM e integração com API.
* **EmailJS:** Serviço para disparo de e-mails sem a necessidade de um backend complexo.
* **Google Fonts:** Tipografia selecionada (*Playfair Display* e *DM Sans*).
